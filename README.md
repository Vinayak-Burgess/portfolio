### 🌟 Project Overview
A high-performance, responsive portfolio environment engineered with a **Cyber-Architect aesthetic**. This deployment serves as the central command for my "100-Day Technical Transformation Protocol," showcasing the intersection of Python automation, offensive security concepts, and aesthetic software design.

### 🚀 Technical Features
* **Terminal Interface:** Integrated Typewriter execution in the Hero section for a "Command-Line" user experience.
* **Trans-Cyber Palette:** A unique UI theme blending high-visibility neon accents with the Trans Pride color variables (`--trans-pink`, `--trans-blue`).
* **Technical Arsenal:** Dynamic skill visualization using CSS custom properties and Grid layouts.
* **Secure QR Uplinks:** Real-time QR generation (using `qrcode.js`) to provide encrypted-style links to professional credentials.
* **Persistent Branding:** Circular profile integration and a responsive, fixed-nav architecture.

---

### 🛠️ The Stack
* **HTML5:** Semantic architecture for SEO and high-speed indexing.
* **CSS3:** Advanced Flexbox/Grid systems utilizing custom variables for global theme management.
* **JavaScript (Vanilla):** Intersection Observer API for scroll-driven animations and DOM manipulation.
* **Typography:** Powered by `Orbitron` and `JetBrains Mono` for professional developer-centric readability.
